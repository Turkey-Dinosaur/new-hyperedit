# HyperEdit

AI-powered video editor built with React 19, Remotion, and Cloudflare Workers.

This app was created using [Mocha](https://getmocha.com). Need help or want to join the community? Join our [Discord](https://discord.gg/shDEGBSe2d).

## Setup & Running

For detailed setup, startup, and shutdown instructions, please see [**SETUP.md**](./SETUP.md).

### Quick Commands
```bash
# Setup (Windows)
./setup-dev.ps1

# Run Vite Dev Server
npm run dev

# Run FFmpeg Server (Highly Recommended)
npm run ffmpeg-server
```

## Features
- AI-driven video editing commands via Gemini
- Multi-track timeline (Video, Audio, Captions, Overlays)
- Dynamic motion graphics using Remotion
- Fast, local transcription via OpenAI Whisper
- Image and video generation via Picasso and DiCaprio agents
